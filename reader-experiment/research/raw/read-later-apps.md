# Read-later apps survey: raw research notes

Researcher angle: Instapaper (+ Send to Kindle digests, Kobo), Matter, GoodLinks, Raindrop.io, Wallabag, Karakeep (ex-Hoarder), Linkwarden, Fabric, legacy Pocket and Omnivore.
Project context: "Send to Daylight" companion apps for the Daylight DC-1 (Android 13, 10.5" grayscale LivePaper tablet, Wacom pen).
Compiled: 2026-10-20.

## IMPORTANT: research-method limitations (read first)

- WebFetch is non-functional in this environment (every host fails with `getaddrinfo ENOTFOUND`), and the egress proxy answers HTTP 403 to CONNECT for every host I probed with curl (hn.algolia.com, apps.apple.com, play.google.com, chromewebstore.google.com, addons.mozilla.org, github.com, mobileread.com, instapaper.com, wallabag.org, docs.karakeep.app, youtube.com, reddit.com, kobo, getpocket.com, wikipedia ...). The proxy status endpoint recorded `connect_rejected ... 403 (policy denial)` for hn.algolia.com. Per the proxy README I did NOT try to route around this.
- WebSearch's own crawler also refuses reddit.com and theverge.com ("domains not accessible to our user agent").
- Therefore EVERYTHING below comes from WebSearch result summaries (which are synthesised by the search tool from the pages it lists) plus the page titles/URLs/snippets it returned. I could not open any page myself. Where a quote is in quotation marks it is text the search tool reproduced from the source page; treat exact wording as "as relayed by search tool", not independently verified. Where the search tool flagged a conflict or low-quality source I say so.
- allowed_domains filters worked for: news.ycombinator.com, mobileread.com, lemmy.*, macrumors.com, talk.macpowerusers.com, macstories.net, blog.instapaper.com, instapaper.com, getmatter.com. HN and MobileRead threads came back as titles+URLs+summaries, which is the best "voice of users" available.
- Reddit content: not reachable at all. HN, MacRumors forums, MPU Talk (talk.macpowerusers.com), MobileRead and Lemmy used as substitutes.
- Confidence labels: [DOC] = vendor docs/blog as relayed; [PRESS] = journalism; [USER] = forum/HN/user voice; [BLOG] = third-party blog/SEO (lower trust).


# PART 1: PER-PRODUCT NOTES

## 1. Instapaper (active; independent since Pinterest sold it back; ~Brian Donohue owner per Pocket-lint)

Platforms: iPhone/iPad (Instapaper 10, Jul 2026), Android (v6.4/6.5), web (new site Jul 2026), Chrome/Arc/Edge, Firefox, Safari extensions, Kindle (email), Kobo (native firmware integration, since Aug 2025), CarPlay (2023).

### Capture
- [DOC] Docs (https://www.instapaper.com/docs/getting-started/install, https://www.instapaper.com/docs/save/browser, https://www.instapaper.com/docs/save/mobile-apps): desktop extension for Chrome, Firefox, Safari (Safari ships with the macOS app); click toolbar icon, a banner confirms the save and lets you add tags, move to a folder or archive "without leaving the page". iOS/Android: pick Instapaper from share sheet. Mobile app also has "Add Link" (paste a URL). Bookmarklet now legacy ("system share sheet in iOS 8 made mobile bookmarklets unnecessary"); desktop bookmarklet redesigned as faster full-page overlay (https://blog.instapaper.com/post/18556429689 multi-page article saving; https://blog.instapaper.com/post/104333776481 "Improving Save to Instapaper").
- [DOC] Save-by-email: each account has a private email address (app Settings > "How to Save") to forward long emails/newsletters (TapSmart guide https://www.tapsmart.com/features/deep-dive-instapaper/?amp=1 ; 2011 TechInch https://techinch.com/blog/add-long-emails-newsletters-and-more-to-instapaper). The Kobo integration does NOT surface email-imported items (the-ebook-reader blog, see Kobo section).
- [DOC] "Bringing Highlights to the Open Web" (https://blog.instapaper.com/post/752995536017178624/bringing-highlights-to-the-open-web): updated browser extensions for Chrome (incl. Arc/Edge), Firefox, Safari add highlighting on any web page, archive-after-save and Send to Kindle.
- [DOC] Paywalled content: Marco Arment's original bookmarklet "has a mechanism to save pages from sites that require logins for full content" by sending the page's HTML from the user's browser (secondhand, via search tool: https://waldo.jaquith.org/blog/tag/instapaper/). A HN user: "Instapaper is absurdly far ahead of Pocket" citing paywalled content Pocket could not store (https://news.ycombinator.com/item?id=44597668 as summarised by search tool). A Hook forum post says server-side fetch cannot authenticate (https://discourse.hookproductivity.com/t/web-article-behind-paywall/3657) - low confidence, conflicting.
- [DOC] PDFs: Instapaper 6.3 Android release notes (Aug 2025): save PDFs from the web or upload; Premium only (https://www.apkmirror.com/apk/instant-paper-inc/instapaper/instapaper-6-3-release/ ; Stuff.co.za column https://stuff.co.za/2025/08/10/instapaper-redux-taking-on-pdfs/ : Instapaper email framed it as fixing "reading PDFs" on phones). No evidence of PDF annotation.
- [DOC] 2026 relaunch (https://blog.instapaper.com/2026/07/28/instapaper-10/ ; coverage: https://www.digitaltrends.com/phones/instapaper-just-had-its-biggest-update-in-years-and-its-packed-with-goodies/ , https://9to5mac.com/2026/07/28/instapaper-update-adds-liquid-glass-home-screen-widgets-new-fonts-more/ , https://alternativeto.net/news/2026/7/instapaper-revamps-website-launches-major-ios-redesign-and-ai-text-to-speech-on-android/): new website (only the second full rewrite since 2008), 3-column reader on large screens, keyboard shortcuts for archive/tag/move, "pages load over 60% faster", old site kept at old.instapaper.com through end of 2026; Instapaper 10 for iOS = Liquid Glass, per-section article counts, sortable folders and tags, 4 new fonts (Literata, New York, Open Sans, Atkinson Hyperlegible), condensed list view, Home Screen widget (in-progress article + recently saved); Android full rewrite of text-to-speech, bringing "AI Voices" (iOS has them since 9.4, Premium).
- [DOC] Instapaper API v2 (29 Sep 2026): OAuth2, single "Authorization: Bearer" header, personal access tokens in a couple of clicks, first-party Python and TypeScript SDKs plus OpenAPI spec, xAuth turned off 30 Sep 2027 (https://blog.instapaper.com/2026/09/29/instapaper-api-v2/). Relevant: a public API is what let third parties (Kobo, KOReader plugin, IFTTT, Obsidian) build on Instapaper.

### Organisation at save time
- Tags (introduced 2024, https://blog.instapaper.com/post/765771980408569856/tags), folders (free), archive, like/star; improved sorting (https://blog.instapaper.com/post/723827342100840448). Extension banner offers tag/folder/archive at the moment of saving. Notes: free tier ~5 notes/month per one 2026 review (low-quality source); Premium unlimited notes.

### E-reader delivery (very relevant)
- [DOC] Kindle digests: Premium overview (https://www.instapaper.com/docs/premium/overview) lists "Kindle Digests: send your articles to your Kindle on a daily or weekly schedule". Needs Kindle email saved in Settings + Instapaper's sending address on Amazon's Approved Personal Document E-mail List. Older sources: up to 50 articles per digest (Gizmodo AU), "send now" button, threshold for number of unread items, schedule (sspai guide https://sspai.com/post/91202). Digest arrives as one compiled document with a table of contents (HN: "emailing the .mobi file with your top saved articles to your Kindle once a day ... a personal newspaper with its own contents page").
- [DOC] Browser-extension "Send to Kindle" for single articles and Android individual "Send to Kindle" were brought back and are Premium-only (blog posts via search tool: https://blog.instapaper.com/post/752995536017178624/bringing-highlights-to-the-open-web , https://blog.instapaper.com/post/746654374752878592/instapaper-android-50-article-list-redesign).
- [PRESS] Feb 19, 2026: Send to Kindle (individual sends AND scheduled digests per Pocket-lint / eReaders Forum) became Premium-only; an Instapaper rep on Reddit explained digest generation is resource-intensive ("parsing articles, downloading images, creating an ePub file, and emailing it"). Premium $5.99/mo or $59.99/yr (was $3/mo until Jan 2024). Kobo users keep integration free per owner Brian Donohue (single-sourced, Pocket-lint). Sources: https://www.androidauthority.com/instapaper-send-to-kindle-paywall-imminent-3635014/ , https://www.pocket-lint.com/instapaper-send-to-kindle-going-behind-paywall/ , https://www.androidpolice.com/your-amazon-kindle-is-losing-yet-another-free-feature/ , https://www.ereadersforum.com/blog/instapapers-send-to-kindle-feature-moves-to-premium/ , https://www.newsminimalist.com/articles/instapapers-send-to-kindle-feature-moves-to-a-paid-subscription-265483fa . Reaction: split between "I'd pay for quality" and "resented paying for previously free feature" (Android Police / Pocket-lint). Lower-trust outlets (smash.news, foxnewsn.com) claim broken automations - uncorroborated.
- [USER] Free-tier behaviour before the paywall (MobileRead, ~Oct 2025, https://www.mobileread.com/forums/showthread.php?p=4545848): "I currently use the free Instapaper feature that sends 10 saved articles to my Kindle each day. But it's a bit annoying as it includes the same articles in the daily packages lots of times." => digest de-duplication (don't resend already-delivered items) is an explicit user pain point.
- [USER] HN 2018: "I really love Instapaper and use it a lot. Especially the send to kindle feature" (https://news.ycombinator.com/item?id=17706597). Old pain: Kindle Touch digests had unusable table of contents and files couldn't be deleted from device (MobileRead 2011).
- [DOC] Amazon constraints: delivery goes via Amazon email address; Instapaper's older help recommended the @free.kindle.com address to avoid 3G delivery fees on legacy Kindles (https://old.instapaper.com/help).

### Kobo
- [PRESS][DOC] Native Kobo-Instapaper integration replaced Pocket; announced 22 Jul 2025, firmware rollout late Aug 2025, all Kobo models "from the original Touch through Clara BW, Clara Colour and Libra Colour" (https://www.androidauthority.com/kobo-instapaper-integration-roll-out-3592013/ ; https://blog.the-ebook-reader.com/2025/08/26/latest-kobo-software-update-adds-instapaper-support/ ; https://goodereader.com/blog/kobo-ereader-news/instapaper-is-now-on-the-rakuten-kobo-e-readers ; https://sixcolors.com/link/2025/08/kobo-instapaper-have-come-together-at-last/ ; https://boingboing.net/2025/09/03/kobo-just-saved-one-of-its-e-readers-best-features.html).
- Setup: More > My Articles > Link with Instapaper; enter a code at kobo.com/instapaper or scan a QR code with a phone. (This is the same pairing pattern Send to Daylight uses.) Articles sync over Wi-Fi and read offline in the E-Ink reader.
- [DOC] Limits per Kobo help (https://help.kobo.com/hc/en-us/articles/33359968957463 via search tool): only articles in the main Instapaper list sync; tags, highlights, notes, videos and PDFs are NOT supported; articles in Instapaper folders do not sync (Reviewed.com via search tool); articles emailed into Instapaper not surfaced (the-ebook-reader). Webp images show a placeholder (MobileRead user).
- [USER] "after a month or so of attempting to use Instapaper with the Kobo, I've decided to return to KOreader and Wallabag" (the-ebook-reader commenter, per search tool; https://blog.the-ebook-reader.com/2025/07/22/kobos-getting-instapaper-integration-pocket-articles-import/ ).
- [USER] Kobo owners treated Pocket as "one of the selling points for Kobo ereaders" and "something other brands didn't have built-in" (https://blog.the-ebook-reader.com/2025/07/12/pocket-support-has-ended-on-kobos-without-any-alternatives/). Kobo lacks any Send-to-Kobo service (reported there too).
- Community plug-ins: Instapaper plugin for KOReader (needs an API token, https://www.mobileread.com/forums/showthread.php?t=372113); eReaditLater alpha Kobo app (KOReader fork supporting Instapaper, https://www.mobileread.com/forums/showthread.php?p=4523064).

### Speed/reliability/offline
- Offline: "saves pages as clean text for offline reading, including on planes and subways" (store listing); HN: Instapaper "rock solid for offline reading"; "couldn't find any other options which can be read offline, support Android and have a reasonable free tier" (https://news.ycombinator.com/item?id=44068524 and 44597668).
- Android complaints (chrome-stats/Play aggregate, 4.6 stars ~12.8k ratings): slow syncing, gaps in PDF sync, reliability glitches, data-loss worries; changelogs mention fixes for sync stalling after app backgrounded, repeated re-saves, improved share-extension performance (https://www.apkmirror.com/apk/instant-paper-inc/instapaper ; https://www.apkmirror.com/?p=12735372).
- Third-party Chrome extensions exist because the official Chrome extension is thin: AcceleReader (shortcuts, offline add; abandoned 2019), Open in Instapaper Text (4.7 stars/510), Instapaper Reloaded (Ctrl+I); official Firefox add-on was removed Jan 2024 and its reviews complained Ctrl+I conflicts with italics in editors (https://chromewebstore.google.com/detail/aaiicdnkfldglpocbdlihoepjfkjplda ; https://addons.mozilla.org/en-US/firefox/addon/instapaper-official/reviews/1635603/).
- TTS: Dec 2025 "AI Voices, Text-to-Speech Redesign, and Android Update" (https://blog.instapaper.com/post/802011928668094464/ai-voices-text-to-speech-redesign-and-android): 17 voices in 8 languages, floating player with playlist, voice switching. Premium: full-text search, permanent archive, unlimited notes, PDF reader, Kindle, TTS, 3x speed reading, ad-free, playlists.

### Why loved / why abandoned
- Loved: simplicity, reliability, offline, third-party ecosystem (Reeder, Kindle, Kobo, IFTTT), direct Pocket import (instapaper.com/pocket), "absurdly far ahead of Pocket" on paywalled content (HN). 
- Complaints: paywalling the free Kindle feature (Feb 2026); privacy worries; free-tier limits; thin official Chrome extension; Android sync flakiness; digest repeats.

## 2. Matter (iPhone, iPad, web, Safari/Chrome/Firefox extensions; NO Android)

- [PRESS] Platform: "As of August 2026, Matter supports iPhone, iPad, and web only"; Android is the most common complaint (https://makerstack.co/reviews/matter-review/ , https://tooliverse.ai/tools/matter). HN commenters "noted that Matter lacks Android support, which was a dealbreaker for some" (https://news.ycombinator.com/item?id=44597668). - Capture: iOS share extension ("Matter for iOS: New Share Extension" https://www.getmatter.com/updates/matter-for-ios-new-share-extension : one-tap save, tags, notes at save time, and "archive without adding to queue"); browser extensions for Chrome, Safari (Mac App Store "Save to Matter", free, "stylized M in your toolbar"), Firefox (https://www.getmatter.com/updates/new-matter-browser-extension ; TechCrunch https://techcrunch.com/2025/05/27/read-it-later-app-pocket-is-shutting-down-here-are-the-best-alternatives ). Extension save methods: toolbar button, right-click a link, keyboard shortcut. - Paywalls: "Save behind paywalls" update - extensions send the page you are signed in to so NYT/WSJ/Bloomberg full articles save (https://www.getmatter.com/updates/save-behind-paywalls). Chrome review: "It handles paywalled articles better than any other extension I've tried." (via search tool; https://extensionauditor.com/scan/matter-knjbgabkeojmfdhindppcmhhfiembkeb).
- Send to Kindle (Premium): approve Matter's sender in Amazon's Personal Document Settings, enter Kindle email in Settings > Connected Accounts > Kindle; "Send to Kindle" in article action menu - "Send any article to your Kindle in just two taps!"; "Behind the scenes, we convert web articles to Kindle-optimized format"; claims better metadata/block-quote/markdown handling than Amazon's own; bulk send on iOS "merges the articles into an ebook, with each article as its own chapter". Also available from web app and extension. (https://www.getmatter.com/updates/send-to-kindle , https://www.getmatter.com/updates/matter-kindle , setup guide https://getmatterapp.notion.site/Matter-Kindle-Setup-Guide-c2f81920f5e549078d83108b617dc792 ).
- TTS: HD text-to-speech - MacStories Selects 2025 named it year's best new feature, "the best one I've ever tested in 16 years of writing about apps" (https://www.macstories.net/stories/macstories-selects-2025-recognizing-the-best-apps-of-the-year/). Podcast/YouTube transcription also.
- Highlights/notes sync to Notion, Obsidian, Roam, Readwise.
- Newsletters: subscribe inside the app via a Matter address; "Subscriptions Inbox".
- Parsing: "near flawless at extracting article text"; "much more pleasant UI/UX than Instapaper or Pocket" (MPU Talk https://talk.macpowerusers.com/t/any-one-using-matter-in-view-to-replace-instapaper-and-pocket-etc/27034 , https://talk.macpowerusers.com/t/readwise-reader-vs-matter-vs-omnivore/35211). "Better article parsing" release affected 100,000+ saved items (https://www.getmatter.com/updates/better-article-parsing).
- Pricing: Premium reported $7.99/mo or $59.99-$79.99/yr (conflicting); free tier generous.
- Complaints: "Matter's share extension has been broken on and off again" on Mac (MacStories reviewer); TTS "period" glitches and mispronunciation; podcast transcripts lack speaker change; "some users see occasional delays before new saves appear when syncing across devices" (Chrome listing review); early social features cluttered the reading experience.

## 3. GoodLinks (iPhone, iPad, Mac, Vision; Apple-only; no account, iCloud sync)

- [DOC] Sync: iCloud only, no separate service/account: "Sync links, articles, highlights, tags, and reading position without needing another web service account" (https://goodlinks.app/help/icloud-sync/). All devices must use same iCloud account with iCloud Drive on.
- [DOC] Capture (https://goodlinks.app/help/how-to-save/): iOS/iPadOS share extension with optional "Quick Save" (Settings > Share Extension > Quick Save: tapping the extension saves immediately and skips the editor); macOS Share menu; Safari extension installed automatically ("Save to GoodLinks", default shortcut Cmd+Shift+S); Chrome, Arc, Edge, Opera, Brave extension (shortcut changeable at chrome://extensions/shortcuts); URL scheme `goodlinks://x-callback-url/save?...&quick=1` (no UI; uses clipboard URL if none given) (https://goodlinks.app/url-scheme/); local API (https://goodlinks.app/api/). Old MacStories claim that Mac lacks share/Safari extension is outdated.
- GoodLinks 2.0 (MacStories https://www.macstories.net/reviews/goodlinks-2-0-the-automation-focused-read-later-app-ive-always-wanted/): highlights + notes with Shortcuts actions (Find/Edit Highlight etc.), customizable Markdown/plain-text export formats, highlight widget; "automation-focused".
- GoodLinks 3 (21 Nov 2025, https://goodlinks.app/releases/3/): Article Sync (Premium) - each article stored as permanent offline copy in iCloud incl. images (option to not sync images), auto-delete read articles after X days (3.1: spare starred), Quick Search / Open Quickly palette, Liquid Glass.
- GoodLinks 4 / 4.1 (4.1 on 12 Oct 2026): AI Custom Actions (OS 27), custom actions sync via iCloud, URL actions on macOS, command-line tool and MCP server for the library (https://goodlinks.app/releases/). MacStories "A GoodLinks Read and Listen Later Shortcut and Custom Action": https://www.macstories.net/linked/a-goodlinks-read-and-listen-later-shortcut-and-custom-action/ .
- Pricing: $9.99 one-time; includes 1 year of feature updates; later features need "Annual Feature Upgrade" IAP $4.99 (or Premium) - unlocked features are kept forever (https://apppricinglab.com/iap/apple/1474335294 , https://goodlinks.app/press/). YouTube: "GoodLinks Made Me Cancel My Readwise Subscription" (https://www.youtube.com/watch?v=OqEbHuvHSOc).
- [USER] MPU Talk: "simpler than Pocket, Reeder, or Instapaper, with no social network attached, no subscription, and no full-blown RSS reader" (https://talk.macpowerusers.com/t/why-use-goodlinks-already-have-reeder-and-pocket/24711). Complaints (older): "syncing, especially of paid articles, seems to not work often"; at the time "no highlighting, no full-text search, no Readwise integration" (since fixed in 2.0). Common pattern: pair Readwise Reader (power) with GoodLinks (casual saving) (HN/MPU summarised by search tool).
- No Android, no e-reader delivery; export of articles as Markdown/PDF/plain text.


## 4. Raindrop.io (web, Mac, iOS, Android; Chrome/Safari/Firefox/Edge/Opera + Arc/Vivaldi/Brave via Chrome ext) - bookmark manager more than reader

- [DOC] Capture (https://help.raindrop.io/install-extension , https://help.raindrop.io/bookmarks , https://help.raindrop.io/mobile-app): extension click > pick collection > optional tags > save; "one-click mode" sends new bookmarks to Unsorted or the last-used collection; extension suggests collections and AI tags from page content; iOS share extension must be enabled once; "Add to Unsorted" share action; Android share target "Save automatically" option. Safari extension works on iOS/iPadOS (other mobile browsers cannot run extensions). "Unsorted" = built-in inbox to triage later. Each bookmark lives in exactly one collection. Trash until manually emptied.
- [DOC] Changelogs (https://help.raindrop.io/changelog/ios , https://help.raindrop.io/changelog/android.md): iOS 5.3.0 (19 Feb 2026) adds "Stella" AI assistant + Shortcuts actions (add/get/delete bookmarks, tags, favorites, save files, get collections); Android 4.7.20 (26 Feb 2026) Stella; Android 4.7.44 (15 Sep 2026, via APKMirror) "tags are saved automatically when you close the tag picker" and better support for links shared from other apps; earlier 4.6.00 fixed broken "Save automatically" in share extension.
- [DOC] Offline: help center says the app does NOT work offline ("An internet connection is required to sync changes and save new bookmarks"); Raindrop's own blog "Top 10 Pocket Alternatives in 2026" (https://blog.raindrop.io/pocket-alternatives/) says Raindrop has no offline reading mode and points to Instapaper/GoodLinks for that; a feature request for offline reading has existed since Oct 2023 (https://better.raindrop.io/feature-requests/p/offline-support-reading-viewing , commenter: requested for six years). Web archive ("permanent copy") is Pro and lives in the cloud; if Pro lapses archived copies become inaccessible and are deleted after ~1 month (https://help.raindrop.io/permanent-copy).
- Pro (~$28/yr US, EUR ~33 incl VAT, $3/mo): AI assistant, full-text search, web archive, reminders, annotations, daily backups, duplicate and broken-link finder, 10 GB monthly uploads (https://raindrop.io/pro ; https://contextbolt.com/blog/raindrop-pricing/). Highlights free.
- [USER] Chrome Web Store (https://chromewebstore.google.com/detail/raindropio/ldgfbffkinooeloadekpmfoklnobpien/reviews): ~4.1-4.2 stars, ~787 ratings, 400-500k users. Praise: ease of use, tag-based finding, "one of the best-built widgets", link-status check. Complaints: popup slow to open, save button missing, "buggy"; paying subscriber said AI organisation suggestions "were not useful and setup took more time than expected". G2: 4.2/5 from 13 reviews; "AI tagging errors... manual sorting more efficient" (https://g2.com/products/raindrop-io/reviews?page=2).
- [USER] HN/MPU: "a great and very polished bookmarking app, but it does not feel like a real Pocket replacement"; macOS save flow "clunky"; unsure it "had a reader mode at all"; annotation "not very ergonomic" (https://talk.macpowerusers.com/t/so-with-pocket-shutting-down-what-read-it-later-service-do-you-recommend/40772 , https://news.ycombinator.com/item?id=44597668). Counter-view: "I use Raindrop.io and Karakeep wired up together. Total cost is under $30/year." (https://news.ycombinator.com/item?id=44073350); "imported all the Pocket stuff with no issues". Raindrop collections can publish as RSS feeds (HN "Does a good read it later app exist?" https://news.ycombinator.com/item?id=46880866) - useful for pulling into KOReader-style readers.
- Press: Fast Company "Raindrop.io Pocket replacement" https://www.fastcompany.com/91352217/raindrop-io-pocket-replacement-read-it-later (not opened).

## 5. Wallabag (open source MIT; self-host or wallabag.it hosted ~EUR 11/yr, supporter tier EUR 30)

- Platforms: web; Android official app (F-Droid 2.6.0 added 3 Jun 2026: newer-Android support, sort by creation date, annotate-button fix, TTS widget fix; offline reading incl. images, tags, speech synthesis; Android 6+; https://f-droid.org/packages/fr.gaulupeau.apps.InThePoche/); iOS: official source repo archived Apr 2026; the original maintainer's app ("Wallabag Reader", v7.6+ closed source with in-app purchases, iOS 17+) is no longer announced as the official wallabag iOS app (https://wallabag.org/news/20260327-important-change-ios-app/ ; https://apps.apple.com/it/app/wallabag-reader/id1170800946); browser extensions (Firefox/Chrome/etc., e.g. Wallabagger); server 2.6.14 (API filter for entries with annotations).
- Features: annotations, tagging rules (RulerZ expression language auto-tag by URL/language/content), export EPUB/PDF/CSV/JSON/HTML, importers for Pocket, Instapaper, Omnivore (Omnivore importer announced Oct 2024; highlights likely unsupported at first: https://wallabag.org/news/20241031-migrate-from-omnivore/ ), Pocket migration guide (https://wallabag.org/migrate-from-pocket/), "So Long, and Thanks for all the Fish: Pocket shuts down but open web remains" (https://wallabag.org/news/20250524-pocket-shutdown/).
- E-readers (official page https://wallabag.org/apps-and-readers/): Kobo via third-party wallabako; Kindle via wallindle; PocketBook via Plop Reader. KOReader has a built-in Wallabag plugin (two-way sync, articles stored as EPUB, annotations, treat articles like books) (https://planet.kde.org/matija-suklje-hook-2025-05-24-trying-out-koreader-and-wallabag-the-first-few-days-and-months/). Wallabako: downloads EPUBs to a Kobo when Wi-Fi turns on, marks article read in wallabag after finishing; needs KoboRoot.tgz + config, a "fake USB connection" tap to rescan; author found it "a bit hacky" vs KOReader; 1.4.0 (May 2022) was first release in ~3 years (https://anarc.at/blog/2022-05-06-wallabako-1.4.0-released/). KOReader login troubles reported ("Could not login to Wallabag server", "Communication with server failed"; a 2021 MobileRead thread - one of https://www.mobileread.com/forums/showthread.php?p=4087808 / p=4087998 / p=4087593, search tool did not say which).

## B. What users repeatedly say they love (distilled; all sources above)

1. One-gesture saving that "just works" from everywhere (share sheet + toolbar button + keyboard shortcut) - Pocket's moat was the open API that put "Save to Pocket" inside other apps (45% of saves came from third parties in 2014).
2. Offline reliability - Instapaper "rock solid for offline reading"; offline failure was Pocket's top complaint ("about half of the articles would not load offline").
3. A save-time moment to organise (tags/folder/archive, or Quick Save to skip it) - Instapaper banner, Matter share ext, Raindrop collections + AI tag suggestions, GoodLinks Quick Save.
4. E-reader delivery without friction - Kobo+Pocket was "one of the selling points for Kobo"; Kobo's code-or-QR link flow replicated by Instapaper; Kindle email requires the approved-sender dance but "Just supply Instapaper with your Kindle's email address and you're in business".
5. Reading experience: clean parsing and typography (Omnivore "best parser and typography"; Matter "near flawless"), good TTS (Matter's HD TTS "best I've ever tested in 16 years"), fonts incl. Atkinson Hyperlegible.
6. Highlights that leave the app (Obsidian/Readwise/Markdown export) - Omnivore's Obsidian sync, GoodLinks custom Markdown export, Matter -> Notion/Obsidian/Roam/Readwise.
7. Ownership and exit: open source/self-host/standard export after two shutdowns; one-time purchase (GoodLinks) vs subscriptions; "no server to shut down".
8. Automation: GoodLinks Shortcuts/URL scheme/CLI/MCP, Raindrop Shortcuts, Instapaper API v2, Karakeep API/CLI/MCP.

## C. Top frustrations (with sources)

1. Free feature turned paid with little warning: Instapaper Send to Kindle -> Premium on 19 Feb 2026 (Android Authority, Pocket-lint, Android Police). Matter HD TTS moved to Premium. GoodLinks article sync is a paid upgrade.
2. Shutdown/data-deletion deadlines: Omnivore ~2 weeks, export only usable with ElevenReader; Pocket data deleted 8 Oct 2025; users "still bitter" (HN).
3. Integration gaps on e-readers: Kobo-Instapaper syncs only the main list - no tags, highlights, notes, videos, PDFs, no folders, no emailed-in items (Kobo help; Reviewed; the-ebook-reader); webp images show placeholders (MobileRead); user returned to KOReader+Wallabag after a month.
4. Digest repeats: free Instapaper Kindle digest "includes the same articles in the daily packages lots of times" (MobileRead, ~Oct 2025). Older: Kindle Touch ToC unusable; can't delete delivered files from device (MobileRead 2011).
5. Platform exclusion: Matter has no Android (dealbreaker on HN); GoodLinks Apple-only; Readeck no native mobile app.
6. Needing the internet to save: Raindrop "An internet connection is required to ... save new bookmarks" and no offline reading since 2023 requests.
7. Server-side fetching can't see what you see (login/paywall): Karakeep headless Chrome copy "can produce a broken snapshot" for logged-in pages; Hook forum on Instapaper/GoodLinks; Linkwarden needs extension.
8. Share-sheet fragility: Instapaper missing from iOS share sheet until you enable it ("swipe left > More"); Matter's Mac share extension "broken on and off again"; GoodLinks Safari extension disappears (help page workaround needs Terminal); Raindrop "Save automatically" share bug; Instapaper Chrome ext shortcut Ctrl+I clashes with italics (Firefox add-on reviews; add-on removed Jan 2024).
9. Slow/heavy clients: Pocket web "dog-slow", extension 1.5 cores; Raindrop popup slow to open (Chrome reviews); Linkwarden 500-950 MB RAM.
10. AI features that disappoint: Raindrop AI suggestions "not useful" (paying subscriber), G2 AI tagging errors; Matter TTS glitches; Karakeep/Linkwarden need Ollama/OpenAI setup.
11. Self-host burden: wallabag "beyond the skills of ordinary users", Wallabako needs KoboRoot.tgz + config and "fake USB" tap; kobo proxies must rewrite init response because Kobo re-syncs its config.
12. Sync lag: Matter "occasional delays before new saves appear"; Instapaper Android "slow syncing", PDF sync gaps; GoodLinks "syncing of paid articles often failed" (old).
13. Parsing failures on complex pages (Matter reviewers; Omnivore pagination; Karakeep "tried hoarder and didn't like list view").

## D. Kindle/Kobo/e-reader delivery patterns worth copying (and not)

- Kindle email: needs the user to (1) find their @kindle.com address, (2) add the sender to Amazon's approved list; digest = compiled doc with TOC; per-article files clutter library (HN: some prefer one Kindle item per article, others like weekly compilation); legacy 3G fee workaround @free.kindle.com. Instapaper says generation is costly (parse, images, ePub, email).
- Kobo: code/QR pairing (kobo.com/instapaper) + built-in "My Articles" over Wi-Fi; stripped-down features; Instapaper free tier suffices (Kobo users keep it free).
- KOReader: Wallabag plugin (two-way sync, annotations, EPUB), Instapaper plugin (API token), Readeck OPDS, Karakeep RSS via News Downloader; eReaditLater alpha.
- Wallabako: marks read state back on finishing; kobodeck writes read status back to Readeck -> bidirectional status is valued by tinkerers.
- Web-to-EPUB tools (EpubPress, dotepub, Epublifier, Show HN local-first tool): users want local conversion with no limits; bundling many articles into one EPUB is a recurring ask ("Turn your read later folder into a physical book", "I turned my Kindle into my own personal newspaper" https://news.ycombinator.com/item?id=47541969 ; KTool dev: links, newsletters via email forwarding and RSS compiled into one magazine delivered at a specific time).
